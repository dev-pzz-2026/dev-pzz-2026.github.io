# 五（辅）行诀概要

> 读《辅行诀脏腑用药法要》记 —— 五行体用、五脏德、补泻五味与诸方撮要

## 一、书与其源流

《辅行诀脏腑用药法要》一卷，题 "梁华阳隐居陶弘景撰"。书以道教修真者须先祛疾、调平脏气立论，尊《汤液经法》为方源，条列五脏虚实病证、补泻方剂与救急诸法，为研究汉魏经方与五行用药体系的重要文献。据书末附录《真伪考》，自 1988 年马继兴《敦煌古医籍考释》收载以来，钱超尘、冯世纶、丛春雨等学者多认为其非伪书，于《伤寒论》研究意义重大。

本书正文九章：



| 章次 | 篇名       | 内容                           |
| -- | -------- | ---------------------------- |
| 一  | 辨肝脏病证文并方 | 肝病证候、小 / 大泻肝汤、小 / 大补肝汤       |
| 二  | 辨心脏病证文并方 | 心病证候（含心包络）、心之小 / 大泻补汤两套      |
| 三  | 辨脾脏病证文并方 | 脾病证候、小 / 大泻脾汤、小 / 大补脾汤       |

## 二、总纲：五行、五脏、五味与德、体、用、补泻、急

全书用药纲领，一言以蔽之：**以五味调五行，以五行治五脏**。每脏各系五行之一，各有其 "德"（本脏气机之性）、其 "体"（本脏之体味）、其 "用"（本脏补益之用味），并依 "苦欲" 定 "急食" 之味。



| 五脏 | 五行 | 德 | 体味 | 用味 | 泻味 | 补泻经旨 | 苦欲急食 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 肝 | 木 | 散 | 酸 | 辛 | 酸 | 以辛补之、以酸泻之 | 肝苦急，急食甘以缓之 |
| 心 | 火 | 耎（软） | 苦 | 咸 | 苦 | 以咸补之、以苦泻之 | 心苦缓，急食酸以收之 |
| 脾 | 土 | 缓 | 辛 | 甘 | 辛 | 以甘补之、以辛泻之 | 脾苦湿，急食苦以燥之 |
| 肺 | 金 | 收 | 咸 | 酸 | 咸 | 以酸补之、以咸泻之 | 肺苦气上逆，急食辛以散之 |
| 肾 | 水 | 坚 | 甘 | 苦 | 甘 | 以苦补之、以甘泻之 | 肾苦燥，急食咸以润之 |

**读图说明**：



* **实线（外环）为相生**：木→火→土→金→水→木；**虚线（内星）为相克**：木→土→水→火→金→木。

* **体、用**：体为本脏之体味，用为本脏补益之用味（补味），二者与 "德" 相配 —— 肝体酸用辛、心体苦用咸、脾体辛用甘、肺体咸用酸、肾体甘用苦；**泻味即体味**（以酸泻肝、苦泻心、辛泻脾、咸泻肺、甘泻肾）。

* **急**：五脏 "苦欲" 之治 —— 肝苦急食甘、心苦缓食酸、脾苦湿食苦、肺苦气上逆食辛、肾苦燥食咸，皆 "急食" 以济其性。

* **化、除**：即《汤液经法》图之 "化"（五味相合而化，如咸之化用）与 "除"（以味除邪，分除温③、除寒④）—— 图中实线相生即化机流转，虚线相克即除邪制约，与体用、补泻互为表里。

## 三、《汤液经法》图：体、用、化、除

书至 "五味互含" 后载《汤液经法》图，陶隐居曰："此图乃《汤液经法》尽要之妙，学者能谙于此，医道毕矣。"（书页 17）图为五边形，标注五味与体用、化除，并有数注：



| 图内标注                        | 释读              |
| --------------------------- | --------------- |
| 辛、咸、甘、酸、苦                   | 五味分列五方          |
| 用木体 / 用火体 / 用土体 / 用金体 / 用水体 | 五脏体用之味（体为本、用为补） |
| 化（化咸）                       | 五味相合而化（如咸之化用）   |
| 除（除温③ / 除寒④）                | 以味除邪，分温、寒二端     |
| 阳进为补，其数七火数也                 | 补法主阳，取数七（火数）    |
| 阴退为泻，其数六水数也                 | 泻法主阴，取数六（水数）    |
| 左、右                         | 图分左右，示升降出入      |

此图与上文五脏补泻表互为表里：**体、用定补泻之味，化、除示五味精义，阳七阴六示补泻法度**。图原为五边形手绘，此处以文字转写其要（原图字迹漫漶，个别标注或与通行整理本有出入）。

## 四、二十五味互含：诸药之精

书页 16 载：经云 "在天成象，在地成形，天有五气，化生五味…… 约列二十五种，以明五行互含之迹，以明五味变化之用"，并谓 "**此二十五味，为诸药之精，多疗诸五脏六腑内损诸病，学者当深契焉**"。二十五味互含如下（据本书原文）：



| 味 / 属 | 木         | 火           | 土          | 金           | 水          |
| ----- | --------- | ----------- | ---------- | ----------- | ---------- |
| **辛** | **桂（为主）** | 椒           | 姜          | 细辛          | 附子         |
| **咸** | 大黄        | **旋覆花（为主）** | 泽泻         | 厚朴          | 硝石         |
| **甘** | 甘草        | 大枣          | **人参（为主）** | 麦冬          | 茯苓         |
| **酸** | 枳实        | 豉           | 芍药         | **五味子（为主）** | 薯蓣         |
| **苦** | 黄芩        | 黄连          | 白术         | 竹叶          | **地黄（为主）** |

原文曰："味辛皆属木，桂为之主，椒为火，姜为土，细辛为金，附子为水；味咸皆属火，旋覆花为之主…… 味苦皆属水，地黄为之主，黄芩为木，黄连为火，白术为土，竹叶为金。" 每味皆属一行，其 "为主" 之药居本行本位，余四药互含于其余四行，故曰 "五行互含"。

## 五、五脏病证文并方

### （一）肝（木）・病证与四方

**证候**：肝虚则恐，实则怒。肝病者必两胁下痛，痛引少腹；虚则目无所见、耳无所闻、心澹澹然如人将捕之；气逆则耳聋、颊肿。邪在肝则两胁中痛、寒中，恶血在内则胠善瘕、节时肿。取厥阴、少阳血者。

**陶云**：肝德在散，以辛补之、以酸泻之；肝苦急，急食甘以缓之，适其性而衰之也。



| 方名   | 主治                                             | 组成                                                | 煎服                 |
| ---- | ---------------------------------------------- | ------------------------------------------------- | ------------------ |
| 小泻肝汤 | 肝实，两胁下痛引少腹迫急，当有干呕                              | 枳实（熬）、芍药、生姜各三两                                    | 清浆三升煮取一升，顿服；不瘥即重作  |
| 大泻肝汤 | 头痛目赤，多恚怒，胁下支满而痛连少腹迫急无奈                         | 枳实（熬）、芍药、甘草（炙）各三两；黄芩、大黄、生姜（切）各一两                  | 水五升煮取二升，温分再服       |
| 小补肝汤 | 心中恐疑，时多恶梦，气上冲心，越汗出，头目眩晕                        | 桂枝、干姜、五味子各三两；大枣十二枚（去核，一方作薯蓣）                      | 水八升煮取三升，温服一升，日三服   |
| 大补肝汤 | 肝气虚，恐惧不安，气自少腹上冲咽，呃声不止，头目苦眩不能坐起，汗出心悸，干呕不能食，脉弱而结 | 桂心、干姜、五味子各三两；旋覆花、代赭石（烧，一方作牡丹皮）、竹叶各一两；大枣十二枚（一方作薯蓣） | 水一斗煮取四升，温服一升，日三夜一服 |

小补肝汤加减：心中悸者加桂枝；冲气盛者加五味子；头苦眩者加术；干呕者去大枣加生姜；中满者去大枣；心中如饥还用枣；咳逆头苦痛者加细辛；四肢冷、小便难者加附子一枚（炮）。

### （二）心（火）・病证与两套方

**证候**：心虚则悲不已，实则笑不休。心病者心胸内痛，胁下支满，膺背肩胛间痛，两臂内痛；虚则胸腹胁下与腰相引而痛。邪在心则心中痛、善悲、眩仆。经云：诸邪在心者，皆心胞代受。

**陶云**：心德在耎（ruan，软，意为祛弱），以咸补之、以苦泻之；心苦缓，急食酸以收之。

**第一方（心）**：



| 方名      | 主治                                      | 组成                                          | 煎服                                                 |
| ------- | --------------------------------------- | ------------------------------------------- | -------------------------------------------------- |
| 小泻心汤（一） | 心中卒急痛，胁下支满，气逆攻膺背肩胛间，不可饮食，食之反笃           | 龙胆草、栀子（打）各三两；戎盐如杏子大三枚（烧）                    | 以酢三升煮取一升，顿服，少顷得吐瘥                                  |
| 大泻心汤（一） | 暴得心腹痛，痛如刀刺，欲吐不吐，欲下不下，心中懊憹，胁背胸支满，腹中迫急不可奈 | 龙胆草、栀子（捣）各三两；苦参、升麻各二两；豉半升；戎盐如杏子大三枚          | 酢六升先煮五味得三升去滓，内戎盐煮取二升，服一升，当大吐，吐已必自泻下即瘥（一方无苦参，有通草二两） |
| 小补心汤（一） | 胸痹不得卧，心痛彻背，背痛彻心                         | 栝蒌一枚（捣）、薤白八两、半夏半升（洗去滑）                      | 白截浆一斗煮取四升，温服一升，日再服（一方有杏仁无半夏）                       |
| 大补心汤（一） | 胸痹心中痞满，气结在胸，时从胁下逆抢心，心痛无奈                | 栝蒌一枚（捣）、薤白八两、半夏半升（洗去滑）；枳实（熬）二两、厚朴（炙）二两、桂枝一两 | 白截浆一斗煮取四升，每服二升，日再（一方有杏仁半升熬，无半夏）                    |

注：小补心汤第一方即《金匮要略》栝蒌薤白半夏汤，主证药味皆符；惟《金匮》用白酒一斗，本书用白截浆一斗（《外台》谓白酒即白截浆，古又称 "酢"，即今黄酒 / 米醋）。

**第二方（心包络）**：

**证候**：心胞气实者受外邪之动，胸胁支满，心中澹澹大动，面赤目黄，善笑不休；虚则血气少，善悲，久不已，发癫仆。



| 方名      | 主治                                   | 组成                                                     | 煎服                 |
| ------- | ------------------------------------ | ------------------------------------------------------ | ------------------ |
| 小泻心汤（二） | 胸腹支满，心中跳动不安                          | 黄连、黄芩、大黄各三两                                            | 麻沸汤三升渍一食顷，绞去滓，顿服   |
| 大泻心汤（二） | 心中怔忡不安，胸膺痞懑，口中苦，舌上生疮，面赤如新妆，或吐血、衄血、下血 | 黄连、黄芩、芍药各三两；干姜（炮）、甘草（炙）、大黄各一两                          | 水五升煮取二升，温分再服，日二    |
| 小补心汤（二） | 血气虚少，心中动悸，时悲泣，烦躁，汗出，气噫，脉时结           | 代赭石（烧赤酢淬三次打，一方作牡丹皮）、旋覆花、竹叶各二两；豉一两（一方作山萸肉）              | 水八升煮取三升，温服一升，日三服   |
| 大补心汤（二） | 心中虚烦，懊憹不安，怔忡如车马惊，饮食无味，干呕气噫，时或多唾，脉结而微 | 代赭石（烧赤酢淬三次打，一方作牡丹皮）、旋覆花、竹叶各三两；豉（一方作山萸肉）、人参、甘草（炙）、干姜各一两 | 水一斗煮取四升，温服一升，日三夜一服 |

### （三）脾（土）・病证与四方

## 十、校读札记（据本书原文，与通行整理本之异同）



1. **肾之补泻**：本书作 "肾德在坚，以苦补之、以甘泻之；肾苦燥，急食咸以润之，至津液生也"；常见通行整理本多作 "以苦补之、以咸泻之；急食辛以润之，致腠理致津液通气也"。本文从本书原文。

2. **二十五味互含**：本书以 "桂、旋覆花、人参、五味子、地黄" 为五味之主（如 "味辛皆属木，桂为之主"），配药与部分通行整理本有出入（如辛行本书作 "附子为水"，有通行本作 "桂为水"）。本文从本书原文。

3. **心分两套方**：第一方主本脏（龙胆草、栀子、戎盐；栝蒌薤白半夏汤），第二方主心包络（黄连、黄芩、大黄；代赭石、旋覆花、竹叶、豉），二者病位、药法判然。

4. **大补脾汤药味**：本书原文辨识作 "莪术"，据方义与通行整理本当作 "白术"，录此存疑待考。

5. **大泻脾汤**：原文抄本有 "枳实"，按全书通例（大泻汤六味＝五味同药＋本脏小泻汤主药），当无枳实，本文径从通例。

6. **剂量校勘**：小补脾汤加减中 "加茯苓一分" 等，原书注引《本草经集注》"四分成一两"，疑 "分" 为 "两" 之误。

7. **白截浆**：即酢浆、米醋（亦通名白醋），小补心汤（栝蒌薤白半夏汤）以之代白酒，义出一源。

## 结语

《辅行诀》以五行统摄五脏、五味，以 "德" 明脏性，以 "体用" 定补泻，以 "急食" 济苦欲，以 "互含" 尽药精，又以二十余首小大方剂示其施用 —— 其于《伤寒论》诸方之渊源，可谓活水源头。学者能于此图（《汤液经法》图）谙之，则 "医道毕矣"。本文撮其概要，方剂药味、煎服之法悉依本书原文，临证应用仍当四诊合参、遵法度而权变。
